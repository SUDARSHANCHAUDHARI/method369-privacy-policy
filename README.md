## Editing

`PRIVACY_POLICY.md` is the source of truth. `index.html` carries the same content for GitHub Pages and must be updated in the same commit — Pages serves `main` at the repository root with no build step, so a change to the Markdown alone does not reach the published page.

This README no longer duplicates the policy text. It used to, which left three copies of the same document drifting apart; the copy here and the one in `index.html` had both fallen out of date.

The [Method369 app repository](https://github.com/SUDARSHANCHAUDHARI/Method369/blob/main/PRIVACY_POLICY.md) keeps an identical copy for developers reading the code.
